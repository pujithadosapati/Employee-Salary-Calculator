## Employee Salary Calculator
## Project Overview
The Employee Salary Calculator is a Python-based application that calculates employee gross salary, total deductions, and net salary using configurable salary rules.
The application provides salary details based on employee basic salary, allowances, provident fund, professional tax, and estimated income tax.
## Objectives
Calculate employee gross salary.
Calculate salary allowances.
Calculate employee deductions.
Determine final net salary.
Store employee information using dictionaries.
Implement reusable functions.
Validate numeric inputs.
Keep salary rules configurable.
## Technologies Used
Programming Language: Python
Concepts: Dictionaries, Lists, Functions, Loops, Conditional Statements
Exception Handling: try-except
## Features
Sample employee salary calculation.
New employee salary calculation.
Automatic HRA calculation.
Automatic allowance calculation.
Provident fund deduction.
Professional tax deduction.
Progressive income tax estimation.
Gross and net salary calculation.
Input validation.
Detailed salary slip generation.
## Salary Calculation
Gross Salary = Basic Salary + HRA + Other Allowances
Total Deductions = PF + Professional Tax + Income Tax
Net Salary = Gross Salary - Total Deductions
## Installation and Execution
Step 1: Install Python 3.
Step 2: Open the project folder in VS Code or another Python editor.
Step 3: Open the terminal.
Step 4: Run the program:bash
python salary_calculator.py
Step 5: Select an option from the menu.
